🔎 Detailed Service Breakdown

🔴 TrojAI DETECT — Pre-Deployment Red Teaming & Risk Audit

TrojAI DETECT is the pre-deployment testing engine. Analogous to penetration testing in traditional software, DETECT subjects your ML models to a battery of adversarial attacks, integrity checks, and risk audits before they reach production. It covers Generative AI (LLMs), NLP, and Tabular models.

📊 Dataset Registry

Central catalog of curated evaluation and training datasets used for pentest campaigns and integrity audits. Supports tabular and NLP data formats with detailed configuration.

🤖 Model Registry

Stores and manages all ML models under assessment — LLMs, NLP classifiers, tabular classifiers. Wraps models uniformly so the DETECT engine can query them.

🔴 LLM Pentesting

Automated adversarial testing campaigns against generative models. Configures attack libraries, manipulations, and output evaluators to systematically find jailbreaks and safety failures.

⚔️ Attack Libraries

Extensive library of standard and custom attacks: character-based, word-based perturbations for NLP; tabular corruptions; and prompt-injection / jailbreak templates for LLMs.

🔀 Manipulations

Optional text transformations applied on top of attack prompts — misspelling, encoding changes, language translation — to increase attack coverage and test filter bypass.

📋 Output Evaluators

Automated judges that score model responses for safety, correctness, and alignment. Support LLM-as-judge and classifier-based evaluation to quantify red-team results.

✅ Integrity & Risk Audit

A series of default and custom checks grouped into categories — Robustness, Explainability/Bias, Security/Privacy, Performance/Methodology — ensuring data-science best practices and responsible AI standards.

📝 Testing Configuration & SDK

JSON-driven configuration for datasets, models, attacks, and integrity checks. The TrojAI SDK provides a Python interface for programmatic evaluation runs and CI/CD integration.

🛡️ TrojAI DEFEND — Runtime Firewall & Protection

TrojAI DEFEND is the real-time AI firewall — a scalable Kubernetes deployment (written in GoLang) that sits between users and your LLMs. It intercepts every request and response, evaluates them against configured Policies → Rule Groups → Rules, and takes action: PASS, FLAG, BLOCK, or REDACT.

📜 Firewall Policies

Top-level objects owning a Client ID that routes traffic. Each Policy contains an ordered list of Rule Groups and proxy settings (block message, model target, type: Standard / MCP / OpenAI Compliance).

🔧 Rule Groups

Reusable bundles of rules. One Rule Group can appear in many Policies — edit once, apply everywhere. Example: a "Baseline Security" group with prompt injection + PII detection, shared across all use cases.

🎯 Prompt Injection Detection

Fast classifier-based model that scores inputs for injection attempts. Configurable confidence threshold (default 60%). Blocks adversarial prompts before they reach the model.

🔒 PII Detection (5 variants)

Basic (regex), With Context (NER + contextual scoring), Scoring Pipeline (regex → format validation → context scoring), Neural (deep-learning sequence labeling), and Pattern Matching (custom regex). All support redaction and per-entity configuration.

🤖 TrojGuard Security LLM

Purpose-built security LLM evaluating 12 harm categories in a single call: Prompt Injection, Violent/Non-Violent Crimes, Sex Crimes, Child Exploitation, Specialized Advice, Hate, Self-Harm, Sexual Content, Indiscriminate Weapons, IP, Privacy.

📏 Governance (Trooper Model)

Fine-tuned guardrails model accepting natural-language policy descriptions. 13 built-in protections (Illicit Activities, Prompt Security, PII, Violence, Hate, Misinformation…) plus unlimited custom policies. Chain-of-thought reasoning explains blocks.

⚠️ Content Moderation & External

Harmful Output Detector (fast classifier, 5 harm categories), Azure Content Safety, BYO-ML Classifier, BYO-LLM (bring your own moderation LLM with custom payload/response templates).

🔍 Pattern & Code Rules

Suspicious Character Count, Repetition, Language, Misspelling, Custom Blocklist, Base64 Encoding, Source Code Detection, Secret Detection, Suspicious Pattern Monitor, Malicious & Insecure Code Detector, System Prompt Leakage.

📈 Monitoring, Exploration & Browser Extension

After the firewall takes action, TrojAI provides rich observability and end-user tools.

🔍 Firewall Explorer

Centralized dashboard to review, filter, and analyze all firewall events. Filter by action (PASS/FLAG/BLOCK/ERROR), time, policy, rule group. Historical event data remains queryable.

🌐 LLM Monitor (Browser Extension)

Chromium browser extension that applies firewall protection directly in the browser for users interacting with LLMs. Supports OIDC authentication and configurable rulesets.

📊 Prometheus Metrics

The firewall exposes Prometheus-compatible metrics for integration with Grafana, PagerDuty, and other observability platforms. Enables alerting on block rates, latency, and error spikes.

🔌 Firewall Proxy API

RESTful API endpoints for programmatic integration. Supports proxying to any LLM backend, with full header-based routing via x-eag-clientid.

Fully hosted SaaS version — instant access with no infrastructure management. Ideal for teams wanting to get started quickly.

Self-hosted on your Kubernetes cluster. Deploy on AWS, GCP, Azure, or custom Helm charts. Includes Helm values reference and architecture documentation.

Dedicated deployment guide for the TrojGuard Security LLM via NVIDIA Triton Inference Server. Includes GPU setup, model loading, and AWS walkthrough.

Full REST API documentation for platform automation. Python SDK for programmatic evaluation runs, CI/CD pipeline integration, and custom workflow orchestration.
